# IEEE ISGIS Student Branch — Website

Official website of the **IEEE ISGIS Student Branch** at the Institut Supérieur de Gestion Industrielle de Sfax (ISGIS).

The website provides a modern digital platform for showcasing our Student Branch, activities, events, Chapters and Affinity Groups, achievements, and membership opportunities.

🔗 **Live Website:** [ieeeisgissb.vercel.app](https://ieeeisgissb-keetos-projects.vercel.app/)

---

## ✨ Features

- **Home** — Overview of the IEEE ISGIS Student Branch and its activities
- **About Us** — Information about who we are, our mission, and our community
- **Our Work** — Highlights of our activities, initiatives, Chapters, and Affinity Groups
- **Events** — Showcases past events and upcoming activities
- **Chapters & Affinity Groups** — Overview of our technical Chapters and Affinity Groups
- **Awards** — Highlights our awards, competition results, and achievements
- **Join Us** — Information about IEEE membership, its benefits, and how to join
- **Contact Form** — Allows visitors to contact the Student Branch directly through the website
- **Interactive Location Map** — Leaflet-powered map showing our location
- **Newsletter Integration** — Newsletter subscription system powered by Google Apps Script
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/IEEE-ISGIS-SB-Devteam/SB-website.git
cd SB-website
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser to view the website locally.
